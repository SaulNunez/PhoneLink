# GPIO
The following GPIO pins of the ESP32 are used for connecting to peripherals.

## DTMF

| Pin | Function |
| --- | --- |
| 34 | Q1 DTMF |
| 35 | Q2 DTMF |
| 36 | Q3 DTMF |
| 39 | Q4 DTMF |
| 33 | StD DTMF |

# SLIC module

| Pin | Function |
| --- | --- |
| 16 | Phone Unhooked |
| 17 | Slic Ring Mode |
| 18 | Forward Reverse Slic |

# I2S Input

| Pin | Function |
| --- | --- |
| 26 | I2S Serial Clock |
| 25 | I2S Word Select |
| 22 | I2S Data Output |
